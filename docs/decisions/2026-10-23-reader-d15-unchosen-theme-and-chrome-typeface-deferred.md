## Question

When a reader never chose a theme, does it follow the operating system, for new profiles only or existing ones too? Which face do menus and buttons use?

## Options in the brief

- **(a) OS theme for new profiles; Bricolage.** Bricolage is the heading font [UI-22, UI-23]. Cost: Not estimated.
- **(b) Existing profiles follow the OS once.** Overrides readers who chose light [UI-22]. Cost: Not estimated.
- **(c) OS on first visit only.** P1.4 as specified [UI-22]. Cost: Not estimated.
- **(d) Menus and buttons in Literata.** The body font [UI-23]. Cost: Not estimated.

## The review's recommendation

The review's (8.5): OS theme for new profiles, Bricolage.

## What the ruling sets

S12.3 sets the chrome face; S12.4 builds the theme rule (with D02). Cost: S12.3: 0.75 session; S12.4: 1 session.

## What the 2026-10-23 rulings change for it

- D02 (a), ruled on 2026-10-23, says an OS-following theme reaches new profiles only (S12.4). Option (b) here, existing profiles following the OS once, would need D02 revisited.

- UI-23 makes the chrome face a choice made with the design track, whose note F1 agreed Bricolage.
